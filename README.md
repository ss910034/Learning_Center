# 學習中心 Learning Center

一個以「人類圖閘門」為第一個主題的學習網站雛形：教學、64 閘門圖鑑（含生活範例）、小知識、抽考與學習檢核。

> 目前為**方向確認用的雛形（prototype）**，純靜態網站，不需安裝任何東西。

## 快速預覽

直接用瀏覽器打開 `index.html` 即可，或在專案目錄執行：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

之後也可以直接開啟 GitHub Pages（Settings → Pages → 選擇分支）就能上線。

## 網站規劃

### 資訊架構

| 頁面 | 內容 | 狀態 |
|---|---|---|
| 首頁 | 學習路徑導覽、進度總覽、每日小知識 | ✅ 雛形完成 |
| 教學 | 6 課人類圖基礎（每課含生活範例） | ✅ 雛形完成 |
| 64 閘門 | 閘門圖鑑：易經卦象、能量中心、關鍵字、說明、生活範例、相關通道；可搜尋／篩選 | ✅ 雛形完成 |

| 學習進度 | 已學閘門、各中心進度、課程完成度、測驗紀錄、建議複習清單 | ✅ 雛形完成 |

### 學習檢核機制

- **標記已學**：每個閘門與課程都可標記完成，首頁與進度頁顯示整體進度。
- **抽考**：題型包含「編號→名稱」「閘門→能量中心」「關鍵字→閘門」「敘述→閘門」，每題附解說。
- **範圍可選**：可考全部 64 閘門，或只考「已標記已學」的閘門（檢核模式）。
- **弱點追蹤**：答錯的閘門記錄下來，結果頁與進度頁列出「建議複習」清單，可一鍵回到該閘門重讀。
- **成績紀錄**：保留最近 50 次測驗成績，通過標準預設 80%。

所有紀錄存在瀏覽器 `localStorage`，不需帳號、不上傳任何資料。

### 技術選擇（雛形階段）

- 純 HTML / CSS / Vanilla JS，hash 路由的單頁應用，零依賴、零建置流程。
- 內容全部集中在 `js/data.js`（閘門、通道、課程、小知識），之後要增修內容或新增主題（例如通道、輪迴交叉、其他學科）只需要編輯資料檔。
- 自動支援深色模式、響應式版面。

### 檔案結構

```
index.html      # 頁面骨架與導覽列
css/style.css   # 樣式（含深色模式）
js/data.js      # 內容資料：64 閘門、36 通道、6 課教學、小知識
js/app.js       # 路由、渲染、抽考引擎、學習紀錄
```
