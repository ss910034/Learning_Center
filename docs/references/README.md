# 參考資料資料夾

這個資料夾是 `hd-scholar` 知識顧問 agent 的資料來源。
要讓網站的進階內容（例如 Ra 原典的 384 條逐爻關鍵字）有憑有據，請把可信的參考資料放進來。

## 可以放什麼

- 你自己整理的筆記（`.md`、`.txt`）
- 書籍重點摘要（例如《人類圖：區分的科學》、《The Definitive Book of Human Design》的章節筆記）
- 上課講義的文字整理
- 逐爻關鍵字對照表（建議格式見下方）

## 建議格式：逐爻關鍵字

新增檔案 `lines-keynotes.md`，格式如下，agent 會依據它建檔：

```
## 閘門 1
- 1爻：（關鍵字／說明）
- 2爻：（關鍵字／說明）
...
```

## 使用方式

資料放好之後，在 Claude Code 對話中說：
「請用 hd-scholar 依據 docs/references 的資料，撰寫（或審校）○○內容」。

## 注意

- agent 被指示：沒有本資料夾佐證的原典細節，一律不憑印象撰寫。
- 參考資料僅用於核對事實與改寫為原創白話內容，請勿放置與散布大量受版權保護的原文。
